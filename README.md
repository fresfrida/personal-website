# Personal website

A small home for Frida on the web.

[Visit fresfrida.vercel.app](https://fresfrida.vercel.app)



## The story

I made this page while learning Claude and exploring what AI can build. I wanted one quiet place that felt like me, with a simple way to find my work on GitHub.

It is intentionally small. There is a short introduction, one link, and enough space for the page to breathe.

## How it feels

The page uses warm cream, terracotta, and olive tones. Soft colour moves slowly in the background, while the main card stays clear and easy to read.

The same page adapts to desktop and mobile screens. There are no menus to learn and no extra steps between arriving and finding my work.

## How it works

The whole site lives in one `index.html` file. The HTML and CSS are kept together, with no framework, package manager, build step, or external dependency.

For local preview, the project can be served with Python:

```bash
python3 -m http.server 8090
```

Then open `http://localhost:8090`.
